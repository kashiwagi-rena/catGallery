# 栄養士コンシェルジュ — Phase 0 試作

子どもの食事で悩む親向け「栄養士コンシェルジュ」の試作（Phase 0：土台部分）のソースコードです。
2026-11-22に Muse の試作環境で構築したものを保存用に置いています。

## Phase 0 の範囲

- アカウント：表示名・メールアドレス、先回り通知タイミング（日曜19時）
- 子どものプロフィール：生年月から月齢を自動算出、アレルギー（表示枠組みから選択）、苦手なもの、かかりつけ医の診療時間メモ
- 食材マスタ：初期データ123品目。アレルギー区分は2026年4月改正の表示基準（義務9品目＋推奨20品目＝29品目）を土台にし、表記ゆれは別名として保持（別名検索が可能）
- 未食ステータス管理：子ども × 食材ごとに「未食／試した／様子見／食べた」を記録

## 構成

- `client/` — 画面側（React + TypeScript）
- `server/` — サーバー側の処理とデータ定義（`src/seed-foods.ts` が食材マスタ123品目）
- `drizzle/` — データベースのテーブル定義（SQL）

## 注意

- これは試作環境向けのコードです。本番では、決定済みの構成（PWA＋メールリンク認証、Cloudflare＋Turso）へ移行する前提です。
- チャット相談・確認キュー・未食エンジン（給食との照合と先回り通知）は Phase 1 以降で、ここには含まれません。
- 実際のアカウント情報や子どもの記録データは含まれていません（食材マスタの初期データのみ）。
