# Othello (Pygame)

Pygameで作ったオセロ（リバーシ）です。1ファイル（`othello.py`）で動きます。

## 遊び方

```bash
pip install pygame
python othello.py
```

起動するとモード選択画面が出ます。

| キー | モード |
| --- | --- |
| `1` | コンピュータ対戦（自分が黒・先手） |
| `2` | 人対人（同じ画面で交互にクリック） |

- 置けるマスにはヒントの点が表示されます
- 置ける手がない場合は自動でパスになります
- `R` キーでリスタート、`1` / `2` キーでいつでもモード切替（最初から）

## 実装メモ

- 盤面ロジック（裏返し判定・合法手・パス・終局判定）と描画を分離
- CPUはマスの重み付き評価（角を最優先）＋裏返し枚数で手を選択
